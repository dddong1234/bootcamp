# 🏋️ Pose 키포인트 기반 운동 횟수 카운터

> **YOLO Pose 키포인트 추출 체험 + 노이즈·스무딩이 카운팅 정확도에 미치는 영향 분석**

> 📂 **데이터·도구 안내**
> 이 과제는 **YOLO Pose를 직접 한 번 돌려 키포인트 추출을 체험**한 뒤, 정밀한 정확도 실험은 **정답이 보장된 합성 테스트 데이터**(`squat_test.mp4`, `squat_keypoints.csv`)로 진행한다. 정답(8회)이 정확하고 노이즈가 제어되어 있어 실험 결과가 깔끔하게 드러나기 때문이다.
> 과제를 끝낸 뒤에는 실제 사람 영상으로 도전해 보자. 캐글의 **"Gym Workout/Exercises Video Dataset"**(squats, push-ups 등 운동별 영상 클립 제공)을 받아 YOLO Pose를 직접 돌려보면 실전 감각까지 익힐 수 있다. 단, 이 데이터셋은 정답 라벨이 없으므로 영상을 보고 횟수를 직접 세어 정답을 만들어야 한다.

---

## 🚀 한눈에 보기 — 무엇을 하는 과제인가

운동 영상 속 사람의 **무릎 각도**를 신호로 바꿔서 스쿼트 횟수를 자동으로 센다. 그런데 그 신호에는 **떨림(노이즈)**이 있어서 횟수를 잘못 세게 된다. 이 노이즈를 **스무딩(전처리)**으로 얼마나 줄일 수 있는지를 **실험으로 측정·분석**하는 것이 이 과제다.

> 한 문장 요약: *"키포인트 신호의 노이즈가 카운팅을 망친다 → 스무딩으로 고친다 → 얼마나 좋아지는지 숫자로 증명한다."*

### ✅ 시작하기 전에 (이것만 알면 됨)

1. **무거운 학습(training) 없음.** 모델을 새로 훈련시키지 않는다. YOLO Pose는 이미 만들어진 모델을 가져다 쓰고, 나머지는 각도 계산·실험·분석이다.
2. **메인 실습은 정답 8회짜리 합성 데이터로.** YOLO는 한 번 "체험"만 하고, 정밀한 정확도 실험은 정답이 보장된 CSV로 한다.
3. **코드보다 분석이 핵심.** 셀을 돌리는 게 끝이 아니라, 나온 그래프와 숫자를 보고 "왜 이런가"를 적는 것이 점수의 대부분이다.
4. **순서대로만 하면 된다.** 노트북 맨 위에 적힌 실행 순서를 그대로 따라가면 막히지 않는다.

### 📋 진행 순서 요약

```
STEP 1  환경 준비 (파일 올리기)
STEP 2  YOLO 체험 + 각도 신호 만들고 노이즈 관찰        [RQ1]
STEP 3  스무딩 없이 세보고 오차 기록 (기준점)            [RQ2]
STEP 4  스무딩 윈도우별 정확도 비교 ★핵심 실험★          [RQ3]
STEP 5  임계값 민감도 미니 실험                          [RQ4]
STEP 6  결론 정리 (노트북 빈칸 채우기)
```

## 1. 과제 배경 및 목적

YOLO Pose는 사람의 몸에서 17개의 관절 키포인트(어깨, 팔꿈치, 무릎 등)를 찾아준다. 이 키포인트만 있으면 별도의 무거운 학습 없이도 '관절을 얼마나 굽혔는가'를 계산할 수 있고, 이를 이용해 스쿼트나 팔굽혀펴기 같은 반복 운동의 횟수를 자동으로 셀 수 있다. 헬스케어·홈트레이닝 분야에서 실제로 쓰이는 기술이다.

**하지만 Pose 모델이 추정한 키포인트는 프레임마다 미세하게 흔들린다(노이즈).** 이 노이즈를 그대로 두면 운동 횟수를 잘못 세게 된다. 이 과제의 목적은 단순히 횟수를 세는 프로그램을 만드는 것이 아니라, 다음을 직접 실험으로 확인하는 것이다.

- 비전 모델이 내놓는 신호에는 노이즈가 존재한다는 사실을 눈으로 확인한다.
- 그 노이즈가 실제 결과(카운팅 정확도)를 얼마나 망치는지 수치로 측정한다.
- 스무딩(전처리)으로 얼마나 개선되는지, 그리고 과하면 어떤 부작용이 있는지 검증한다.

---

## 2. 학습 목표

1. **YOLO Pose를 직접 실행**해 키포인트를 추출하고, 그 좌표를 의미 있는 **feature(관절 각도)**로 변환하는 과정을 이해한다.
2. 실제 비전 신호에 **노이즈가 존재함을 시각화로 확인**하고, 그 원인을 추론한다.
3. **전처리(스무딩)의 효과를 정량적으로 평가**하는 실험을 직접 설계하고 수행한다.
4. **정답(ground truth) 라벨을 기준으로 정확도/오차를 계산**하는 머신러닝 평가의 기본 흐름을 익힌다.

## 3. 연구 질문 (Research Questions)

이 과제는 아래 네 가지 질문에 답하는 방식으로 진행한다. 각 질문에 대한 그래프와 결과를 만들어 답하면 그대로 보고서가 된다.

| | 질문 |
| --- | --- |
| **RQ1** | 관절 각도 신호에는 어떤 형태의 노이즈가 존재하는가? (시각화로 확인) |
| **RQ2** | 노이즈는 운동 횟수 카운팅 정확도를 얼마나 떨어뜨리는가? |
| **RQ3** | 이동평균 스무딩은 정확도를 얼마나 개선하는가? 적절한 윈도우 크기는? |
| **RQ4** | 각도 임계값(threshold)은 정확도에 얼마나 민감한가? (미니 실험) |

## 4. 진행 방법 및 파이프라인

전체 처리 흐름은 다음과 같다.

```
영상 → YOLO Pose (17 키포인트) → 관절 각도 계산(feature)
     → 상태머신 카운터 → 스무딩·임계값 실험 → 정확도 평가
```

### 단계별 설명

- **키포인트 추출:** YOLO Pose로 프레임마다 17개 관절 좌표를 얻는다.
- **각도 계산:** 세 관절(예: 엉덩이-무릎-발목)로 무릎 굽힘 각도를 구한다. 사람 위치·키·카메라 거리와 무관한 불변 feature가 된다.
- **카운터(상태머신):** 각도가 임계값 아래로 내려갔다가(앉음) 다시 위로 올라오면(섬) 1회로 센다. 두 개의 임계값을 두어 노이즈에 덜 민감하게 만든다.
- **실험:** 스무딩 윈도우 크기를 바꿔가며 카운팅 결과를 정답과 비교한다.
- **평가:** 절대 오차 = |예측 횟수 − 정답 횟수| 로 정확도를 측정한다.

### STEP 2. YOLO 체험 + 각도 신호 만들고 노이즈 관찰 [RQ1] (25분)
- [ ] **(2-A) YOLO Pose 직접 체험:** 영상에 YOLO Pose를 한 번 돌려 키포인트가 어떻게 나오는지 확인한다. (합성 스틱맨 영상은 인식이 안 될 수 있으나 정상)

- [ ] 노이즈가 왜 생기는지 원인을 한 문장으로 적는다.

### STEP 3. 노이즈의 영향 측정 [RQ2] (20분)
- [ ] 스무딩 없이 카운트해 정답과의 오차를 기록한다.

### STEP 4. 스무딩 실험 [RQ3] — 핵심 (35분)
- [ ] 윈도우 크기(1, 3, 5, 7, 9, 11, 15, 21)별로 카운트하고 오차를 표·그래프로 만든다.
- [ ] 오차가 가장 작은 윈도우를 찾고, 너무 큰 윈도우에서 오차가 다시 커지는 현상을 관찰한다.

### STEP 5. 임계값 민감도 미니 실험 [RQ4] (15분)
- [ ] down 임계값을 바꿔가며 정확도 변화를 본다.

### STEP 6. 결론 정리 (10분)
- [ ] 노트북 마지막의 결론 템플릿 빈칸을 본인 실험 결과로 채운다.
